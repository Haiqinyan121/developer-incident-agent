# HTTP 上游超时排障手册

## 超时分类

- 连接超时：在限定时间内未能与上游建立 TCP 连接。
- 读取超时：连接已经建立，但未能及时收到完整响应。
- 连接池超时：客户端无法在限定时间内获得可用连接。

## 排查顺序

1. 根据异常类型确认是连接、读取还是连接池阶段超时。
2. 检查 DNS、网络连通性、上游健康状态和客户端连接池指标。
3. 对照上游接口延迟分位数，确认超时阈值是否合理。
4. 只有幂等请求才考虑有限次数重试，并配置退避与总超时。
5. 为超时类型、上游地址和耗时记录结构化日志，但不要记录令牌等敏感信息。

盲目增加超时时间可能延长故障恢复时间，并造成请求和连接持续堆积。
